## 🚀 What It Is
Batch Image Resizer for Windows is a straightforward image batch resizer that handles the tedious part of working with lots of pictures. Load a folder, choose how big the images should be, which format they should end up in, and how much quality to keep — then let the app do the rest across every file. Because it works on whole batches instead of single images, it fits neatly into the routines of web publishers, store owners, and anyone who regularly prepares many photos at once.

## ✨ Key Features
> Everything you need to prepare large sets of images without touching them one by one.

- 📐 **Bulk resizing** — Shrink or scale entire folders of images by exact dimensions, percentage, or a target edge length in one go.
- 🔄 **Format conversion** — Switch images between JPEG, PNG, WebP, and other common formats while resizing them in the same job.
- 💾 **Preset library** — Store your go-to size, format, and quality combinations as presets and reuse them instantly for future batches.
- 🏷️ **Bulk renaming** — Apply consistent name patterns and sequential numbers to your output files so big folders stay tidy.
- 🎚️ **Quality tuning** — Adjust compression and quality per batch to keep files small without giving up the sharpness you need.

## 🎯 First Steps
1. Start Batch Image Resizer and drag in a folder or select the images you need.
2. Set your target dimensions by pixels, percentage, or longest edge.
3. Choose an output format and quality level, or apply a saved preset.
4. Add an optional renaming pattern for cleaner output filenames.
5. Pick a destination folder and run the batch to convert and resize everything at once.
